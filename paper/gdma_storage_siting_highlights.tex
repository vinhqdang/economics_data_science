\section*{Highlights}
\begin{itemize}
\item Grouped model averaging learns forecast weights from commitment cost, not accuracy.
\item Soft GDMA cuts day-ahead commitment cost by 12\% on 125 grid areas, five continents.
\item Oracle inequality and segment recovery proved for the fixed-$G$ estimator.
\item 6\% of areas are worse off; no systematic income gradient is found.
\item Better commitment rules lower the value of storage and change where to site it.
\end{itemize}
